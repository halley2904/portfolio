# Halley Patel · Portfolio

Next.js, TypeScript and Tailwind CSS. Deployed on Vercel.

## Edit content
Everything (text, links, metrics, projects, case studies) lives in **`content/site.ts`**.
Edit that file and commit; Vercel rebuilds the site automatically.

- **Photo:** add `halley.jpg` to `public/`, then set `photo: '/halley.jpg'` in `content/site.ts`.
- **Résumé:** add the PDF to `public/` (for example `halley-patel-resume.pdf`), then set `resume: '/halley-patel-resume.pdf'`.
- **New project:** copy one object in the `projects` array and change its fields.

## Run locally
```
npm install
npm run dev
```
